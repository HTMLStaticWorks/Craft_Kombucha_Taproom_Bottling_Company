# KOVA — Single Page Craft Kombucha Website

A responsive single-page concept inspired by the hospitality-first feel of The Brewery, but with an original KOVA visual identity and layout.

## Included
- Single-page website
- Maximum 6 menu items
- Standalone CTA not included in menu
- No login, signup or dashboard
- Working hamburger from 300px through 1100px
- Light/dark theme toggle with localStorage persistence
- Flavour cards
- Brewing story
- Taproom
- Wholesale
- Contact form UI
- Newsletter UI
- Social links
- Responsive footer
- Mobile breakpoints down to 300px

## Brand
KOVA is a short creative brand name used for this concept. Replace it if you prefer another name before launch.

## Replace before production
- Email, phone, address and opening hours
- Social profile URLs
- Form submission endpoint
- Newsletter provider
- Product photography / image URLs if you have licensed brand photography
- Privacy and Terms pages

## Run
Open `index.html` in a browser. No build step is required.
